# 数据报传输实现

`stella-transport` 实现可替换的有界数据报契约和 0.1 UDP 后端。规范的端点、路径大小
和关闭要求以传输规范为准。`DatagramTransport` 只承载完整的不可信 Stella 数据报：它
报告数值源端点、原子发送一个数据报、公开本地端点和保守能力，并支持有界取消。它不
解析 Stella 头部、选择对等密钥、认证端点、分片以太网帧或重试受保护的数据包。

一个 `UdpTransport` 拥有一个绑定到明确 IPv4 或 IPv6 地址的 Tokio UDP 套接字。双栈节点
创建两个实例，避免双栈通配符产生不明确的映射地址。配置规定数值绑定地址和 1,200 至
65,507 字节的最大数据报大小，默认值为 1,200。发送会在调用 Winsock 前拒绝非 UDP 端点、
地址族不匹配和超出限制的数据报；部分发送被视为永久套接字故障。

为防止截断，后端用由套接字独占的 65,535 字节复用暂存区接收。超出 Stella 配置限制的
数据报被丢弃；调用方输出不足时返回类型化错误且不写入输出；其他情况只复制一次精确
字节。这样不会把截断前缀交给 `stella-proto`。

每项操作在等待套接字 I/O 前订阅 Tokio watch 通道。关闭发布幂等的终止值，等待中的发送
和接收会唤醒并返回 `Shutdown`，新操作立即拒绝。错误不包含数据报字节，并区分配置、
地址族、长度、输出缓冲区、关闭和操作系统 I/O 类别。
