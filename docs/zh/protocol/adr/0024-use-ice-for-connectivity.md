# ADR 0024：使用 ICE 和 STUN 建立自动对等连接

- 状态：已接受
- 日期：2026-08-31

## 决策

Stella 0.2 采用 RFC 8445 的 ICE 候选、连通性检查、候选对优先级和提名模型，并使用
RFC 8489 STUN 从承载数据的同一 UDP 套接字发现服务器反射地址。客户端收集有界的
本机、全局 IPv6、服务器反射、自动映射、对等反射和中继候选；不要求用户手工配置
端口映射。

已认证控制器只在已授权对等节点间传递短期 ICE 凭据和候选代次。候选地址与 ICE
成功均不是 Stella 身份或成员授权；候选对完成双向检查和提名后，仍必须运行完整的
Stella 对等握手，才能传递以太网帧。

## 后果

常见家庭 NAT 可以自动建立 UDP 直连，已有的 Tailscale、EasyTier 或同局域网地址也可
自然成为本机候选。对称 NAT 和 UDP 阻断仍可能让所有直连失败，因此 Relay 是目标架构
中的必需路径。
