# ADR 0019：在使用授权状态前认证控制会话

- 状态：已接受
- 日期：2026-08-30

## 决策

TLS 完成后，控制器和客户端以精确消息 ID 交换 `SERVER_HELLO`、`CLIENT_HELLO` 和
`NODE_AUTH`。控制器通过 TLS 导出器、双方 nonce、身份和公钥构造转录并验证节点签名，
随后才检查注册状态或 Bearer 凭据。只有提交后的成功 `AUTH_RESULT` 才创建已认证会话。
失败认证不会回显攻击者控制的文本，并在小幅随机延迟后关闭。

## 后果

Stella 身份被密码学地绑定到单一 TLS 1.3 连接，令牌不会在呈现节点密钥认证前使用。认证
阶段按顺序执行，这增加了授权往返，但活动循环永远不会看到部分注册状态。
