# ADR 0025：维持待命 Relay 兜底路径

- 状态：已接受
- 日期：2026-08-31

## 决策

每个在线 Stella 0.2 客户端在进行直连探测的同时维持至少一个有界 Relay 分配或连接。
首个标准中继方案使用 TURN，并必须提供 TCP 443 上的 TLS 承载；对于只允许 HTTPS 或
显式代理的网络，参考部署还将提供安全 WebSocket 承载。

Relay 与控制器应用流分离，可以同机部署但不能让数据拥塞阻塞授权和心跳。控制器签发
短期 Relay 凭据。Relay 只转发完整的加密 Stella 数据报，不能获得会话密钥或解密、学习
和修改以太网帧。

## 后果

互不兼容的 NAT 或完全阻断 UDP 的网络仍能通过允许的出站 443 连接组网。Relay 会增加
服务器带宽和流式队头阻塞，因此客户端优先使用健康直连，并在 Relay 工作时继续低频尝试
升级为直连。
