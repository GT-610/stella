# ADR 0007：通过 TLS 1.3 和 TCP 运行控制平面

- 状态：已接受
- 日期：2026-08-29

## 背景与决策

控制平面承载身份质询、加入凭据、成员关系、端点、策略和撤销状态，需要有序可靠传输、
双方认证、保密性、完整性、重放防护与显式版本协商。0.1 使用仅受 TLS 1.3 保护的长期 TCP
连接，Rust 实现使用 `rustls` 和 `tokio-rustls`，禁用 TLS 1.2、early data、重新协商和
明文回退。控制器可使用公有 CA、私有 CA 或显式固定 SPKI 的自签名证书。

节点在受保护通道内用 Ed25519 签名认证，控制器在 TLS 握手中证明其证书私钥持有，节点在
应用认证中证明 Stella 身份密钥持有。控制消息采用显式二进制编码，四字节大端长度前缀不
计入消息体；零长度和超过 1 MiB 的消息体会被拒绝。

## 后果

设计采用成熟安全通道，同时保持语言无关的小型应用协议。TCP 队头阻塞可用于低频控制
消息。实现必须处理部分读取、有界缓冲、证书轮换、固定值滚动、超时和应用认证失败。
