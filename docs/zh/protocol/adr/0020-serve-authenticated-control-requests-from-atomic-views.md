# ADR 0020：从原子视图提供已认证控制请求

- 状态：已接受
- 日期：2026-08-30

## 决策

每个已认证连接使用一个顺序活动会话循环，一次完成一个请求。授权线程提供只读的
`network_session_view`，在单个 redb 读事务中返回本地节点、网络、本地成员关系及所有在线
对等节点的成员关系和端点租约。会话从同一视图签发授权、编码策略，并构建 `JOIN_RESULT`
和完整 `PEER_SNAPSHOT`；0.1 可在状态变更时总是发送完整快照而不构造增量。

## 后果

每个发出的授权、策略、修订和对等记录描述一个一致的授权快照。完整快照比增量消耗更多
字节，但避免根据分别读取的记录编造变更历史，并受网络泛洪成员上限约束。
