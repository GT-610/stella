# ADR 0022：从控制器重建客户端转发状态

- 状态：已接受
- 日期：2026-08-31

## 决策

客户端只持久化操作员意图和长期信任材料：本地 Ed25519 身份、控制器地址和名称、控制器
ID、SPKI 固定值、显示名、传输设置、TAP 选择与目标网络 ID。令牌只在命令执行时保留在
会脱敏和清零的内存中。每条 TLS 连接由一个控制监督器和一个顺序事件循环拥有；授权、
策略、epoch、修订、对等记录和关联状态均为连接本地内存。

## 后果

重启和重连不会把序列化的控制器输出当作当前授权。任意控制故障会立即禁用 TAP 转发、
清除对等会话和接收状态，再以 250 ms 至 30 秒的完整抖动退避从新的加入和快照重建。
