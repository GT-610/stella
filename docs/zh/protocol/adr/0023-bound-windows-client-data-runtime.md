# ADR 0023：限制 Windows 客户端数据运行时

- 状态：已接受
- 日期：2026-08-31

## 决策

一个 `ClientDataRuntime` 拥有一个有界 UDP 套接字和每个活动网络一个独立
`NetworkDataPlane`。每个网络拥有一个选定的 TAP-Windows 适配器和专用阻塞工作线程，
两个方向均使用有界队列。控制器快照会在后续帧使用前协调；epoch、策略、授权、对等节点
或端点变更清除受影响会话和转发状态。会话确认后固定到精确 IP 和 UDP 端口，重新握手前
不会迁移。

## 后果

停滞的 TAP 消费者不能消耗任意内存，意外源元组不能迁移已建立会话。例行换钥允许有限的
重排包继续接收，授权变化立即失败关闭。首个实现使用每个活动 TAP 一个阻塞线程和一个共享
UDP 接收缓冲区。
