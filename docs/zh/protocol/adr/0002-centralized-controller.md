# ADR 0002：使用集中式自托管控制器

- 状态：已接受
- 日期：2026-08-29

## 背景

虚拟网络需要一个可理解的成员关系、撤销、策略、版本协商和对等发现授权方。分布式
共识和全局发现会扩大威胁模型，不属于首个实现的目标。

## 决策

每个部署包含一个逻辑上的自托管控制器。它认证节点并签发当前网络和对等状态；未来可
为可用性复制该控制器，但不改变单一授权方语义。发现完成后，符合条件的对等节点直接
交换数据。控制器不在正常单播数据路径上，中继服务留给未来扩展。

## 后果

策略和撤销有单一来源。控制器中断会延迟新会话和策略变更，现有会话最多在其有界租约
期间继续。控制器是高价值的信任和可用性目标。
