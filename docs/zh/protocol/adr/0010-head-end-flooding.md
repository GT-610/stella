# ADR 0010：对泛洪流量使用有界头端复制

- 状态：已接受
- 日期：2026-08-29

## 背景与决策

以太网兼容性需要广播、多播和未知单播投递。0.1 采用头端复制：从 TAP 读取可泛洪帧的节点，
向控制器当前对等快照中的每个其他合格成员发送独立保护的数据包。来自 Stella 对等节点的帧
只写到本地 TAP，不会再转发给另一节点，以避免覆盖网络环路。

控制器为每个网络设置 `max_flood_peers`；参考控制器默认 64 个总成员，0.1 中管理员最多可
提高到 256。超过限制时拒绝新增成员，节点也拒绝超过授权限制的快照。节点对本地发起的
广播、多播和未知单播使用独立令牌桶，默认每网络每秒 1,000 帧、突发 2,000 帧。

## 后果

该行为可预测、直连且独立于底层网络，适合小型虚拟局域网。发送方带宽和 CPU 消耗线性
增长；大型部署需要未来协商的复制机制。
