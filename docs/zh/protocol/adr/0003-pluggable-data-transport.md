# ADR 0003：使数据传输可插拔

- 状态：已接受
- 日期：2026-08-29

## 背景

部分部署具有可直达的 UDP 端点，其他部署已使用 Tailscale 等私有覆盖网络。Stella 应提供
二层语义，但不应承担每种可达性或 NAT 穿透机制。

## 决策

数据平面依赖数据报传输接口，而非具体套接字类型。第一个实现提供 UDP。传输提供端点
表示、有界数据报收发和本地能力信息，不认证 Stella 身份、不授权成员关系、不解释
以太网帧，也不削弱数据包认证。

## 后果

同一协议可运行于公网 UDP、私有 IP 覆盖网络或未来传输上。该抽象引入能力协商和 MTU
问题；每个传输必须保留包边界，或精确模拟包边界。
