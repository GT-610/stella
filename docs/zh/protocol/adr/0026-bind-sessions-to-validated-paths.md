# ADR 0026：将对等会话绑定到已验证路径

- 状态：已接受
- 日期：2026-08-31

## 决策

客户端使用本地唯一的 `PathId` 路由完整数据报。路径封装传输类型、远端投递信息、数据报
上限、代次、存活状态和取消行为；UDP、TURN、TLS Relay 与 WebSocket Relay 对上层提供
同一有界数据报契约。

连接层可以发现、检查、提名和淘汰路径，但不能安装数据会话。路径提名后必须在该精确路径
上重新运行 Stella 对等握手，会话绑定到 `PathId` 和路径代次。首个 0.2 实现切换路径时
建立新会话，不允许原有密钥原地迁移。

## 后果

数据平面不再硬编码数值 UDP 端点，同时保持现有身份、授权、重放和换钥边界。客户端可以
同时保留已提名直连和待命 Relay，并在 Relay 工作时尝试建立新的直连会话。
