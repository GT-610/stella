# ADR 0027：将连接状态与成员记录分开分发

- 状态：已接受
- 日期：2026-08-31

## 背景

0.1 的对等记录同时包含身份、签名成员授权和管理员公布的 UDP 端点。0.2
需要增加变化更频繁、有效期更短的 ICE 代次、凭据、候选地址和 Relay 状态。
如果直接追加到旧记录中，0.1 客户端将无法可靠判断端点记录的边界。

连接状态仍必须与成员变更有统一顺序。已经删除或过期的成员不能因为较旧的
候选地址更新而重新变得可达。

## 决策

0.2 保持 0.1 的对等记录和端点集合编码不变，新增按节点 ID 关联的连接记录
和排序后的连接列表。完整快照同时携带成员列表和当前连接列表；一个已授权
成员在收集或更换候选代次时可以暂时没有连接记录。

成员、静态端点和连接状态共用现有的网络快照修订号。0.2 增加替换或撤销单个
节点连接记录的增量操作。客户端只有在修订号恰好连续且节点仍在成员视图中时
才应用连接增量。

客户端通过 `CONNECTIVITY_UPDATE` 原子发布完整代次；省略代次表示撤销连接
状态而不退出网络。STUN 和 Relay 服务配置独立于网络成员关系分发，Relay
分配凭据只发送给其所有者，不会出现在对等连接记录中。

## 结果

0.1 字节布局在滚动升级期间保持明确，0.2 可以在不轮换成员授权的情况下更新
NAT 映射和 Relay 候选。控制器与客户端需要额外验证成员列表、连接列表和统一
修订序列之间的一致性，并分别保护和更新 Relay 凭据。
