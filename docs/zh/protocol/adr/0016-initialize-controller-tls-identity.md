# ADR 0016：显式初始化控制器 TLS 身份

- 状态：已接受
- 日期：2026-08-30

## 决策

`init` 是唯一创建控制器配置、Stella Ed25519 密钥、TLS 私钥和证书及 redb 状态的命令。它可
生成自签名 Ed25519 证书，也允许管理员安装 CA 签发证书和匹配 PKCS#8 密钥。初始化输出
控制器 ID 和 TLS SPKI 固定值，绝不输出私钥。`run` 仅加载和验证现有部署，不创建或修复
身份文件。

## 后果

部署无需外部证书服务即可启动，同时固定值仍可通过可信渠道分发。丢失固定值或轮换 TLS
密钥需要显式管理员操作，不能静默伪装为首次初始化。
