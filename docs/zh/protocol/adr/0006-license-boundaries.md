# ADR 0006：分离实现与规范许可证

- 状态：已接受
- 日期：2026-08-29

## 背景

实现应保持自由软件属性，协议则必须可被独立项目阅读和重新实现。`.vscode/` 中的参考
仓库使用不同许可证，包含不能复用的材料。

## 决策

Stella 实现代码采用 GPL-3.0，协议规范采用 CC BY-SA 4.0。参考项目只能用于理解架构，
不得复制、改写或派生 ZeroTier 的非自由或其他不兼容材料。若设计实质受参考项目启发，
其 ADR 必须说明高层机制；Stella 的线上格式和实现保持独立。

## 后果

许可证边界明确，可从公开规范构建兼容实现。贡献者必须仔细审查来源，`.vscode/` 参考
树继续排除在提交之外。
