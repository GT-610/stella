# ADR 0008：使用显式且经过检查的线上编码

- 状态：已接受
- 日期：2026-08-29

## 背景与决策

Stella 需要能在对齐、枚举和对象布局规则不同的语言中实现的精确字节格式。所有线上字段
在规范中有显式偏移、宽度、字节序和验证规则；多字节整数使用网络字节序，未知标志位保留
为零，变长值带有有界无符号长度，允许的文本必须是无 NUL 的合法 UTF-8。

Rust 编解码器使用受检查的切片游标、`from_be_bytes` 与 `to_be_bytes`，可借用已验证输入，
但不将不可信字节转换为 Rust 结构，也不通过 `repr(C)` 或 `repr(packed)` 暴露线上结构。
控制平面扩展使用四字节对齐 TLV；未知关键字段拒绝，未知非关键字段在验证边界和填充后
跳过。Serde 只用于可读配置和控制器持久化，不用于 Stella 线上编码。

## 后果

规范而非 Rust 依赖决定互操作性。实现需要更多编解码代码和偏移审查，但获得规范字节、
有界分配、可移植测试向量和明确的畸形输入行为。
