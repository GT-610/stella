# ADR 0009：使用 Stella 0.1 密码学套件

- 状态：已接受
- 日期：2026-08-29

## 决策

0.1 定义一套必选算法：Ed25519 用于长期节点身份签名和控制器签名对象，X25519 用于对等
数据会话密钥协商，SHA-256 用于转录和标识符散列，HKDF-SHA256 用于域分隔密钥与 nonce
前缀派生，ChaCha20-Poly1305 用于数据包认证和可选加密，TLS 1.3 用于控制通道，操作系统
随机数通过 `getrandom` 获取。实现使用成熟 crate，不自行实现密码原语。

节点 ID 取域分隔 SHA-256 输出的前 16 字节。握手对双方临时 X25519 密钥、节点 ID、网络 ID、
控制器 epoch 和协商版本签名。每个方向的序列号不得在同一密钥下重复；会话在一小时、任一
方向 2^32 个保护包或成员关系/epoch 变更前换钥。

## 后果

该套件依赖广泛部署且内存安全的库，提供对等数据会话的前向保密性。Ed25519 和 X25519
不具备后量子安全性；新增套件需要版本化协商、降级防护、测试向量和新的 ADR。
