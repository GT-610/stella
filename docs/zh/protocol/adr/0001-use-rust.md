# ADR 0001：使用 Rust 作为参考实现

- 状态：已接受
- 日期：2026-08-29

## 背景

Stella 处理不可信网络输入、执行密码学操作并调用平台 API。实现需要避免垃圾回收
暂停导致的不可预测延迟，同时保持 Windows、Linux 和 macOS 上的可用性。

## 决策

参考实现使用稳定版 Rust 2021 或更新版本。工作区使用 Tokio 处理异步应用 I/O，
`thiserror` 定义库错误，`anyhow` 处理二进制边界错误，Clap derive 解析命令行，
`tracing` 输出结构化诊断。非安全 Rust 仅限 `stella-tap` 内的操作系统调用，必须
被安全 API 包装并记录每项安全不变量。

## 后果

内存安全和显式所有权降低解析与并发风险。项目接受 Rust 的编译成本、平台 FFI
复杂度，以及保持公开协议独立于 Rust 特定布局的要求。
