# 0. 协议概述

Stella 是开放的二层虚拟局域网协议。它连接可经底层 IP 网络互相到达的节点，并向本地
系统提供以太网帧接口。控制器负责身份、成员关系、策略、版本协商与端点发现；稳定后的
单播和泛洪流量在合格对等节点之间直接传输。

每个虚拟网络由随机 128 位网络 ID 隔离。节点拥有 Ed25519 长期身份，控制器签发成员授权
和策略。数据包使用经认证的对等会话、递增序列号和重放窗口；控制器状态带 epoch、修订和
有界租约，过期状态不得继续授权转发。Stella 不提供 Internet 可达性、NAT 穿透、IP 路由、
代理 ARP 或 DHCP 服务。

实现必须把收到的网络输入视为不可信，在解析、认证和授权前不使用其语义。以太网源 MAC
只在成功认证的数据包上学习。广播、多播和未知单播使用有界头端复制，来自远端对等节点的
帧不会再次向其他对等节点转发。
