# 8. 安全

Stella 将控制器 TLS 身份、节点长期身份、成员授权、对等会话和数据包保护分为独立安全
上下文。TLS 1.3 建立控制通道后，双方以导出器绑定转录证明各自身份。控制器只在验证节点
公钥证明后评估注册或加入凭据。

对等数据会话使用签名的四消息 X25519 握手、双方临时密钥、网络 ID、epoch 和授权绑定。
HKDF 派生方向密钥、nonce 前缀和确认密钥；ChaCha20-Poly1305 提供认证和可选保密性。重放、
降级、错误端点、错误 epoch、过期授权和无效标签都必须失败关闭。会话按寿命、包计数或
授权状态变化换钥，旧会话只在有限接收窗口内保留。
