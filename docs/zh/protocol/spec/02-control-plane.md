# 2. 控制平面

控制器和客户端通过 TLS 1.3 上的有序 Stella 记录交换控制消息。每条记录有四字节大端长度
前缀和固定控制头，消息 ID 在每个方向单调递增，关联 ID 将直接响应与请求匹配。未请求的
快照、增量、授权刷新、错误和关闭通知使用关联零。

会话从 `SERVER_HELLO`、`CLIENT_HELLO` 和 `NODE_AUTH` 开始。认证成功后，客户端可加入或
离开网络、发布端点、请求快照并发送心跳；控制器返回签名授权、规范策略、对等快照和当前
修订。方向、序列、关联、字段或状态不合法时，连接必须关闭。控制器不把端点当作身份凭据，
端点仅在已认证会话中发布和刷新。

0.2 保持旧成员记录不变，新增 `CONNECTIVITY_GENERATION`、按节点排序的连接列表、STUN
服务列表和 Relay 服务列表。连接更新与成员更新共用同一网络快照修订序列；完整快照可允许
某个已授权成员暂时没有候选代次。客户端通过 `CONNECTIVITY_UPDATE` 替换完整代次，省略
代次表示撤销可达性而不退出网络。

候选代次使用带 `SCG1` 魔数的有界记录，包含短期 ICE 凭据、非零代次 ID、角色 tie
breaker、创建/过期时间和最多 32 个严格按优先级排列的候选。候选记录明确区分本机、
服务器反射、自动映射、对等反射和 Relay，以及 UDP、TURN 和 WSS 承载。凭据字节不得进入
日志或状态输出。精确字段偏移和验证条件以英文规范为准。
