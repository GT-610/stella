# 6. 广播

本章定义广播、多播和未知单播帧的分类与有界头端复制。发送方根据每个网络的已认证策略和
对等快照，为每个合格接收方独立保护一个副本。控制器和控制连接不处于数据路径中，接收自
远端 Stella 对等节点的帧不得再次泛洪。

策略限制成员数、每秒泛洪帧数和突发量。节点将受限帧丢弃并计数，不建立无界队列。协议
支持 ARP、IPv4 广播、多播和 IPv6 邻居发现所需的二层传递，但不充当路由器、代理或地址
转换服务，也不保证不同对等节点或传输之间的帧排序。

## 接收侧 flood 分类

会话认证、完整帧重组之后，源 MAC 学习和 TAP 投递之前，接收端按 peer 和流量类别分别限流。
广播、多播按目标 MAC 分类；目标不在接收端本地 MAC 集合中的单播计入未知单播桶。
接收端无法观察发送端 FDB，MUST NOT 根据发送端声明推断其内容。本地单播不计入 flood 桶。

参考实现的各类接收速率和突发值为对应签名策略值的两倍，使用饱和运算。
超限丢弃完整已认证帧，不学习源地址、不撤销会话。状态受授权成员数量约束，并随 peer 删除清理。
重放状态仍在包认证期间提交，策略丢弃的帧不能以相同序号重试。split horizon 和发送侧按帧计费保持不变。
