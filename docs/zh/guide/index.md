# 项目状态

Stella 仍处于标准化前的活跃开发阶段。在第一个可互操作草案宣布稳定前，
协议版本 0.1 和所有公开 API 都可能变更。

版本 0.1 的协议草案、核心编解码器、密码学、UDP 传输、TAP-Windows 访问与
自托管控制器控制平面已经实现。其余 Windows 参考路径按以下顺序实现和验证：

1. Windows 客户端控制连接、重连和状态同步；
2. TAP 与 UDP 数据平面集成及对等会话建立；
3. 双节点以太网、ARP、广播和 IP 连通性测试。

Linux 和 macOS 仍是架构要求，但其设备后端不在第一个功能里程碑范围内。

`stella-server` 可以初始化、管理和运行控制器部署。客户端和集成数据平面
尚未完成，因此 Stella 目前不能组成可用的虚拟局域网。请通过仓库历史和本页
了解里程碑状态，不要将控制器里程碑视为生产网络发布。
