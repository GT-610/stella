# stella

An experimental open source game-oriented virtual LAN project focused on:

- Layer 2 compatibility for LAN-style games
- stronger peer traversal and relay behavior than traditional L2 overlays
- self-hosted open control-plane architecture

Still developing. Also part of my research.
